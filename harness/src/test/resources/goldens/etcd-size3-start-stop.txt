# deliberate — only what this harness creates: the qdisc on the PRIVATE
# iface (resolved, never assumed eth0), DROP rules named by exact peer IP

# exact stress-ng pattern. Exit-code semantics, MEASURED on ubuntu-24.04
# (infra/probes/host-fault-tools-probe.sh): with nothing to undo `tc qdisc
# del` exits 2, `iptables -D` exits 1, `pkill` exits 1 — so on a healthy
# node EVERY line here is expected to fail, and that is silent. A ZERO exit
# means state really did survive a crashed run: the provider WARNs, because
# that also puts the PREVIOUS run's data in question. This is the inverse
# of heal()'s convention, and deliberately so — there the fault is known to
# have been applied, so non-zero is the surprise. Health = curl ON the node against localhost (host
