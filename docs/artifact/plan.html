04 — Honesty

What has not been verified

  • No cost figure in this repo has ever been read from Hetzner. Every euro came from a web page in July 2026. Phase 1.2 is the only authority, and it is free.
  • terraform validate has never run on this machine — terraform is not installed. infra/ is byte-identical to the merge commit.
  • The thesis PDFs cannot be built here: no xelatex, latexmk or pandoc. The Python checks need none of them and all pass.
  • cloud-init.yaml has never booted. Phase 1.4 or the canary closes that.
  • The signed application PDF is already on GitHub — it went up in the initial commit. The exposure has happened; the fix needs a history rewrite and a GC request, since a rewrite alone leaves the blob fetchable by SHA.
The lesson this plan is built on. An earlier draft of it applied an exacting standard to what was already suspected, and none at all to the numbers governing the money — a wrong resource count in the canary's own stop-gate, a 62 % "saving" that was a units error, and a canary command that could not be invoked. Every one was checkable offline in under a minute.
